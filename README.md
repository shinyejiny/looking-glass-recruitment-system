# Looking Glass Recruitment System

A vacancy and candidate tracking application developed for a simulated recruitment agency, **Looking Glass Recruitment Agency (LGRA)**.

---

## Overview

This application manages the end-to-end recruitment process for Looking Glass Recruitment Agency, including vacancy listings, candidate tracking, and application management.

---

## Tech Stack

- **Language:** C#
- **Platform:** .NET (Windows Forms / WPF)
- **IDE:** Visual Studio

---

## Features

- View and manage job vacancies
- Track candidates and their application status
- Record and update candidate details
- Link candidates to vacancies
- Edition-based data management (List Edition + Form Edition)

---

## Project Structure

```
looking-glass-recruitment-system/
├── LookingGlassRecruitmentAgency/   # Main project source
└── LGRA_ListEdition+24formEdition_v10.sln  # Visual Studio solution file
```

---

## Getting Started

### Prerequisites

- Visual Studio 2019 or later
- .NET Framework (version as configured in the project)

### Running the Application

1. Clone the repository:
   ```bash
   git clone https://github.com/shinyejiny/looking-glass-recruitment-system.git
   ```
2. Open `LGRA_ListEdition+24formEdition_v10.sln` in Visual Studio
3. Build the solution (`Ctrl + Shift + B`)
4. Run the application (`F5`)
